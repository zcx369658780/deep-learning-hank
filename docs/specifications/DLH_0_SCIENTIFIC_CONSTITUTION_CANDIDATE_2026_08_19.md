## 1. What this project is

A clean-slate **Deep Learning + HANK** research platform: studying how deep learning can approximate, compress, accelerate, or solve economic objects inside heterogeneous-agent New Keynesian (HANK) models, starting minimal and scaling to multi-region structure later.

Explicitly **not**: a Matlab-to-Python translation; a continuation of Dissertation Chapter 5 R5; a project where legacy Matlab outputs are the numerical oracle.

## 2. Primary working research question (draft, for Owner/ChatGPT decision)

> For a minimal continuous-time heterogeneous-agent model with a small number of regions, can a neural **surrogate/accelerator** trained on a transparent small-grid reference solver approximate the household value/policy block (and later equilibrium objects) such that the neural model passes **economic-residual diagnostics** (HJB/KFE residual, market clearing, mass, boundary) with a measurable, auditable speedup on repeated experiments — i.e., a neural method that is scientifically auditable rather than a black box?

Rationale: the question is narrow enough for a first paper, demands hard economic diagnostics (not just loss), and avoids claiming a literature gap. Full option set in `DLH_0_RESEARCH_QUESTION_AND_CONTRIBUTION_OPTIONS_2026_08_19.md`.

## 4. Minimum economic model contract (baseline summary)

Single-region, **one-liquid-asset** continuous-time HANK baseline:

- Household: asset `a` on grid, idiosyncratic productivity `z` (finite-state Markov); controls: consumption `c`, saving; **inelastic labor supply** in baseline (labor margin and `W_labor` deferred); CRRA utility.
- Borrowing boundary: exogenous limit `a >= a_bar` (candidate `a_bar <= 0`), explicit boundary treatment required at implementation.
- Firms: representative competitive firm per region, Cobb-Douglas `Y = A K^α L^(1-α)`; capital rented from households (household asset = capital; Aiyagari-style closure).
- Stationary distribution: Kolmogorov-forward (KFE) with `mass = 1`, non-negativity, moments.
- Nominal rigidity: **deferred** (baseline is real).
- Fiscal: **minimal** balanced-budget transfer/lump-sum only; debt/fiscal dynamics deferred.
- Steady state: stationary equilibrium (HJB + KFE + aggregates + clearing).
- Transition: conditional perfect-foresight transition path after a one-innovation shock; stochastic-realization simulation deferred.

Full contract with every item decided/caveated: `DLH_0_MINIMUM_ECONOMIC_MODEL_CONTRACT_2026_08_19.md`.

## 6. Shock / experiment concept (first)

- **Aggregate log-TFP AR(1)**, one-innovation conditional (perfect-foresight) transition path.
- Future implementation must freeze: variable, frequency, mean, persistence, innovation normalization, `sigma`/exposure semantics, conditional-path vs stochastic-realization interpretation (candidate parameter values listed in the model contract — to be frozen at DLH-3, not calibrated here).
- Second concept once regions exist: common shock with heterogeneous regional exposure. Region-specific shocks deferred.
