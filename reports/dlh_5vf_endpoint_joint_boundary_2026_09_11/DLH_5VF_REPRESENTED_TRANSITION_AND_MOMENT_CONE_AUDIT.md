# DLH-5V-F — Represented-Transition and Moment-Cone Audit (Issue #54)

Companion report 3 of 5. For every deferred W-active state class, compares the
nonnegative first-moment cone of **actual represented native-grid destinations** with
the continuous admissible drift cone, and proves the finite-process representability

## 1. Destination enumeration rule

From a state `s = (j, i)`, the candidate destination set is

```text
D(s) = { (j', i') : 0 <= j' <= 19, i' >= 0, 10 j' + 7 i' <= N, (j', i') != (j, i) }
```

i.e. **every** represented native-grid node other than the source. The audit does not
assume the accepted transition set `{w_left, w_down, w_T, w_RT}` is exhaustive: any
alternative native-grid displacement is a legitimate candidate (it connects two
actually represented native states; the whole straight segment stays in `D_W` by
convexity because both endpoints are in `D_W`). Ghost/interpolation/virtual states
are excluded by construction (all destinations are real nodes).

## 2. Moment cone

For nonnegative rates `q_d >= 0` on destinations `d in D(s)` with displacement
`v_d = ((10/19) Delta j_d, (7/19) Delta i_d)`,

```text
C_rep(s) = { sum_d q_d v_d : q_d >= 0 }
```

The continuous admissible cone at a `{W}`-only state is `T_W = { mu_W <= 0 }`, where
`mu_W = mu_a + mu_b` and `Delta W` of a destination satisfies

```text
Delta W_d = (10 Delta j_d + 7 Delta i_d)/19.
```

## 3. Key lemmas

**Lemma 1 (W-budget of a destination).** For a top cell with residual `r_j`, the
source W-index is `W_idx(s) = N - r_j`; a destination has
`10 Delta j + 7 Delta i = W_idx(dest) - W_idx(s) <= r_j`. For an **exact-frontier top
cell (`r_j = 0`)**: `10 Delta j + 7 Delta i <= 0` for **every** represented
destination, with equality iff `dest` is same-W (`W_idx(dest) = N`).

*Proof.* `W_idx(dest) <= N` by the node set; subtract `W_idx(s) = N - r_j`. For
`r_j = 0` the upper bound is `0`.

**Lemma 2 (same-W generation).** `10 Delta j + 7 Delta i = 0` iff
`(Delta j, Delta i) = k (7, -10)`, `k in Z` (gcd(10,7) = 1). The primitive rays are
the mirror `(+7,-10)` (`k = 1`, available iff `j <= 12` and `i >= 10`) and the
forward `(-7,+10)` (`k = -1`, available iff `j >= 7`).

**Lemma 3 (sliding-ray membership at exact-frontier cells).** At a cell with
`r_j = 0`, any combination with `mu_W = 0` has positive mass only on same-W
destinations (Lemma 1: every non-same-W destination has strictly negative
`Delta W`). Hence `C_rep ∩ { mu_W = 0 }` is the cone generated by the **available**
same-W rays.

## 4. Obstruction certificate — exact-frontier top cells (`r_j = 0`)

**Lower band `j in {1..6}` (a-interior, b-interior, active set `{W}`).** The state is
an exact-frontier top cell: `W_idx = N`. Same-W rays available: mirror rays only
(`j + 7 <= 13 <= 19`, `i - 10 >= 9` — available; forward `j - 7 < 0` — off-grid),
all with `Delta b < 0`, `Delta a > 0`. By Lemma 3,

```text
C_rep(s) ∩ { mu_W = 0 } = { (mu_a, mu_b) : mu_a >= 0, mu_b = -mu_a <= 0 }
```

(cone of the mirror ray). The **forward-sliding ray** `{(-u, +u), u > 0}` has
`mu_W = 0`, `mu_b = +u > 0` and is continuously admissible (only `W` active
`=> T_W`), but `(-u,+u) ∉ C_rep(s)`. **Obstruction (O_L).**

**Upper band `j in {13..18}` (a-interior, b-interior, active set `{W}`).** Same-W
rays available: forward rays only (`j >= 13 >= 7`; mirror `j + 7 > 19` off-grid),
all with `Delta a < 0`, `Delta b > 0`:

```text
C_rep(s) ∩ { mu_W = 0 } = { (mu_a, mu_b) : mu_a <= 0, mu_b = -mu_a >= 0 }.
```

The **reverse-sliding ray** `{(+u, -u), u > 0}` (`mu_W = 0`, `mu_a = +u > 0`,
admissible) satisfies `(+u,-u) ∉ C_rep(s)`. **Obstruction (O_U).**

These two certificates are exact and airtight: they use only (i) the node-set bound,
(ii) same-W generation, (iii) the availability conditions — no enumeration was
needed.

## 5. Obstruction certificate — additional classes

**Lower band `j = 1`, `r_1 in {1,2,3}` (top cell) — closed-form proof.** Let
`i = i_t(1)`, so `W_idx(s) = N - r_1` with `r_1 in {1,2,3}`.

*Claim P_L: no represented destination has `(Delta b > 0 AND 10 Delta j + 7 Delta i >= 0)`.*

Proof. `Delta b > 0` iff `Delta i >= 1`. For `j' = 0`: `i' = i+1` is represented
(`W_idx = N - r_1 - 3 <= N`), and any `i' >= i+2` has `W_idx >= N + 4 - r_1 > N`
(since `r_1 <= 3`), so is not represented. For `j' >= 1`: `W_idx >= 10 + 7(i+1)
= N - r_1 + 7 > N`. So the **only** `Delta b > 0` destination is `(0, i+1)`, with
displacement `(-1, +1)` and `Delta W = -3/19 < 0`. Next, suppose
`10 Delta j + 7 Delta i = Delta W_idx in {1..r_1} subset {1..3}` (a `Delta W > 0`
destination): if `Delta i >= 0` then `Delta j >= 1` gives `Delta W >= 10`, and
`Delta j = 0` gives `Delta W >= 7`, and `Delta j <= -2` gives `j' < 0` (off-grid),
while `Delta j = -1` gives `Delta W in {-3, +4}` with `+4 > r_1` — contradiction;
hence `Delta i <= -1`, and then `10 Delta j = Delta W - 7 Delta i >= 1 + 7 > 0`, so
`Delta j >= 1`. Thus every `Delta W > 0` destination has `Delta a > 0`,
`Delta b < 0`, and b-drag ratio `-7 Delta i / Delta W = (10 Delta j - Delta W)/Delta W
>= 10/3 - 1 = 7/3` (using `Delta j >= 1`, `Delta W <= 3`). P_L holds.

*Dominance.* If `(-u, +u) = sum q_d v_d` with `mu_W = 0`, the `(0, i+1)` mass
`q_C` contributes `Delta W = -3 q_C/19 < 0`, so the `Delta W > 0` mass must satisfy
`sum q_d Delta W >= 3 q_C` (index units). Its b-drag is at least
`(7/3) sum q_d Delta W >= 7 q_C`, exactly cancelling the `+7 q_C` b-gain of
`(0, i+1)`; the equality-degenerate case (all `Delta W > 0` mass on `(2, i-1)`,
`r_1 = 3`) additionally forces `mu_a > 0` (wrong sign for forward-sliding, which
needs `mu_a = -u < 0`). Hence `mu_b > 0` with `mu_W = 0` is impossible:
`(-u, +u) not in C_rep(s)`. **Obstruction (O_L).** Re-verified exactly over
`N in [190, 260]` (30/30 cells; exact separation test, Section 8).

**Upper band no-helper cells — closed-form certificate, bounded supplementary
obstruction evidence.** The no-helper set is closed-form: a
`(Delta a > 0 AND Delta W >= 0)` destination needs a same-orientation helper with
step `k = Delta j >= 1` and `Delta W_min(k) = 10 k - 7 ceil(10 k / 7) <= r_j`
(`Delta W_min(1..5) = 3, 6, 2, 5, 1`; higher `k` with `Delta W_min in {1,2}` require
`j + k <= 19`, i.e. `k <= 6` here). For `r_j in {1,2}` the only on-grid helpers are
`k = 3` (`(j+3, i-4)`, `Delta W = +2`; needs `j <= 16` and `r_j >= 2`) and `k = 5`
(`(j+5, i-7)`, `Delta W = +1`; needs `j <= 14` and `r_j >= 1`). Hence the no-helper
set for `N >= 190` is exactly

```text
{ j in {15,16}, r_j = 1 }  u  { j in {17,18}, r_j in {1,2} }
```

(the required `i >= 4` / `i >= 7` hold automatically since `N >= 190`). At these
cells no represented destination has `(Delta a > 0 AND Delta W >= 0)` — the
*necessary* condition for excluding the reverse-sliding ray. **Sufficiency** (the
ray `(+u, -u) not in C_rep(s)`) is verified exactly, cell-by-cell over
`N in [190, 260]` (60/60 cells, no exceptions; exact separation test, Section 8),
but is **not** presented here as a full symbolic dominance proof: it is bounded
supplementary enumeration evidence, **non-controlling** for the terminal. The other
62 upper `r_j in {1,2}` top cells (those with an on-grid `k = 3` or `k = 5` helper)
are exactly representable — not obstructions.

These additional classes are reported for completeness; the `r_j = 0` certificate of
Section 4 is closed-form, universal over the `N >= 190` family, and alone forces the
terminal.

## 9. Which frozen assumption causes the obstruction

The frozen grid/domain places the primitive same-W destination of the missing
orientation off-grid in the a-interior endpoint bands:

```text
forward (j-7, i+10) requires j >= 7  -> off-grid for j in {1..6}   (a_dest < 0)
mirror  (j+7, i-10) requires j <= 12 and i >= 10 -> off-grid for j in {13..18} (a_dest > a_max)
```

while the frozen exact same-process contract (i) admits only actual represented
native-grid destinations (no ghost/interpolation/virtual states, no reflected mass),
and (ii) requires exact first-moment equality for tangent motion (`mu_W = 0`; no
inward-normal injection to disguise the mismatch — explicitly forbidden by Issue #54
unless the Owner later changes the approximation contract). At an exact-frontier cell
every non-same-W destination strictly decreases `W`, so no nonnegative combination
can realize `mu_W = 0` in the missing orientation. The obstruction is a lattice
(structural) property of the frozen domain/grid, not an algebra or economics error.
