# 科学变更权限

更新：2026-09-18。承接项目源 2026-08-20 同名规则；与路线锁配套，不降低原有科学边界。

A 类等价工程修改：import/path 修复、日志、manifest、类型检查、等价重构和性能优化，可在 bounded Issue 内推进。名为 bug 的修改若实际改变方程/算子/数据/实验解释，仍是科学修改。

B 类科学修改：状态空间、资产定义、预算/借贷/积累、HJB/Hamiltonian/控制/边界、KFE/质量、市场出清、聚合、参数/分布/校准矩、数据来源/版本/年份/地区/变量、缺失/异常/归一化、网络能力/损失/目标/度量/基准、实验处理/对照/冲击与解释，均需事前 scientific review。

B 类中涉及 `DLH-WL-V1-20260918` 锁定战略、家庭经济结构、calibration、算子语义、KFE/GE/Results 授权的变化须 Owner 明确批准。未锁定的本阶段小型 ML 实施细节由 Reviewer 在 Issue 中事前冻结，Builder 不自行扩大。

科学 blocker：方程、核算、校准、数值证据或实验设计不可信，暂停受影响用途。工程 blocker：环境/代码/测试故障允许 bounded repair。Metadata blocker：旧状态/命名/链接只做最小修复。

不得删除失败实验、隐瞒不支持假设、放宽容差制造 PASS，或用科学路径改动修理无关文档。变更须保留 authority、差异、证据、适用范围与解释边界。
