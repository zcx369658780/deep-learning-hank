# 分层测试、缓存与计算预算

更新：2026-09-18。科学正确性与可复现性不降级；停止无信息增益的重复计算。

| 层 | 检查 | 默认触发 |
|---|---|---|
| T1 | 小型代数、shape、sign、方向、守恒、边界/异常测试 | 相关实现修改 |
| T2 | 已接受 artifact 的 hash、manifest、输入和科学不变量 | 复用历史证据 |
| T3 | 本次聚焦科学实验 | 科学依赖变化或明确任务 |
| T4 | 独立复现/稳定性检查 | 新重要 claim 或关键依赖变化 |
| T5 | 广域集成回归 | 跨模块改动、依赖升级、生产替换或 Results 验收 |

文档/路径 guard 修复只做静态或对应聚焦检查；不默认 T3–T5。同步任务昂贵科学调用=0、pytest=0。新离线模块不应 import 后自动启动 household solver。

一次实验生成一次持久化产物，多个断言共享产物，不各自运行完整搜索/trajectory。必要独立复现必须重新计算，不能读取第一次缓存冒充独立复现。记录实际实验次数、算子重组数、训练次数、耗时和跳过检查及理由。

缓存键绑定科学代码/合同、输入数据、grid/domain、参数、初始化、算法与容差、随机种子及相关数值环境；不绑定整个 Git HEAD。文档修改不使科学缓存失效；关键科学依赖变化必须失效。读缓存仍校验 hash/输入/完整性/不变量，记录 cold/cached 模式。

历史 guard 绑定 accepted commit/blob、输入与输出，不要求当前 git status 永远干净或从远古基线到今天 cumulative paths 永远等于旧 allowlist。当前任务的 diff 在集成时按具体基线检查。被授权修复的测试自身不能又要求 byte-identical。

#73 旧四路径 guard 与已授权五路径 remediation 不兼容；这是已接受的低风险测试合同债务。未修复前不得声称全仓全绿；本轮不修测试、不重跑数值。不预先保证其他未跑测试的状态。

每个实验事前指定时间及昂贵调用上限，任一耗尽停止。第一轮离线原型默认最多 30 分钟计算；训练次数、epoch/step 上限与必要复现须在 Issue 明定后才能运行。不得自动增加预算或换超参数追求 PASS。
