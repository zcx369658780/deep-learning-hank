# 科研证据等级与引用资格规则

最后更新：2026-06-23  
适用范围：文献检索、Zotero / Obsidian 入库、论文综述、模型定位、实证/模型结果、论文 claim  
规则状态：长期规则 / 证据与引用边界

## 0. 总原则

本项目 MUST 区分“候选信息”“机器提取信息”“人工核验信息”和“可正式引用证据”。GPT / DSH 不得把未经核验的信息包装成论文核心依据。

## 1. 证据等级

### E0：元数据 / 标题级

来源示例：标题；作者、年份、期刊；关键词；检索结果；仅有 abstract 页面但未读摘要。

允许用途：候选文献清单、检索方向判断、待读队列。

禁止用途：正式文献综述的实质 claim、模型贡献定位、研究空白强判断、论文正文关键引用。

### E1：摘要 / 简介级

来源示例：abstract、editor summary、项目简介、书目页面摘要。

允许用途：初筛、研究方向判断、文献候选分类、草稿中的 caveated note。

禁止用途：支撑强结论、替代全文阅读、作为核心理论 / 模型 / 实证依据。

### E2：机器提取全文 / 机器笔记 / 未人工核验

来源示例：OCR / PDF parser 提取全文；GPT / DSH 自动摘要；Zotero note 自动抽取；未人工核对的表格、公式、模型描述、实证结论。

允许用途：初稿提醒、结构化笔记、候选 evidence map、人工核验清单。

禁止用途：最终论文正文强 claim、直接引用关键结论、声称“该文证明 / 发现 / 建立”而未人工核验。

### E3：人工核验证据

来源示例：用户或研究者人工阅读并确认的全文段落；人工核验过的公式、模型、数据、表格、估计结果；人工确认的关键页码、原文段落、结果解释；经人工复核的 Zotero / Obsidian 笔记。

允许用途：正式论文文献综述、模型定位、方法比较、实证/模型结果讨论、投稿版本引用支撑。

## 2. 论文引用资格

正式论文中，只有 E3 或等价人工核验来源，才可支撑：

- 研究空白；
- 模型创新；
- 机制解释；
- 文献批评；
- 实证结论；
- 政策含义；
- 与已有文献差异。

E0/E1/E2 MAY 用于候选清单，但 MUST 标注 caveat。

## 3. Claim 边界

MUST NOT 写：

- “已有文献证明……”除非 E3 支撑；
- “该文发现……”除非读过全文或关键段落；
- “文献普遍认为……”除非有多篇 E3；
- “没有文献研究……”除非有系统检索和人工复核；
- “模型已经验证……”除非模型诊断和输出证据通过对应 gate。

SHOULD 写：

- “根据当前 E1 摘要信息，该文可能相关，需全文核验。”
- “机器提取结果提示该文可能讨论……，尚不能作为正式引用。”
- “经人工核验的段落显示……”

## 4. 文献笔记规则

Obsidian / ResearchVault 笔记 SHOULD 包含：

- evidence_level；
- source_type；
- human_verified；
- page_or_section；
- quote_or_paraphrase；
- citation_candidate；
- caveat；
- next_action。

机器生成笔记 MUST 默认 `human_verified: false`，除非用户明确确认。

## 5. Zotero 入库规则

自动入库 / 批量导入 MUST NOT 默认提升证据等级。Zotero item 的存在只表示“文献被收集”，不表示已读、可引用、已核验或支持论文 claim。

## 6. 数据和模型结果证据等级

模型 / 数据输出也适用类似证据等级：

- D0：文件存在但未审计；
- D1：结构 / manifest 通过；
- D2：机器诊断通过但未人工解释；
- D3：人工核验并可进入论文草稿；
- D4：可投稿级复核，包含可复现脚本、manifest、解释边界和稳健性说明。

没有 D3/D4，不应写 Results prose 的强结论。

## 7. 审稿/投稿风险规则

投稿稿件中 MUST 避免：

- 用标题级文献堆砌综述；
- 用摘要级信息批评别人模型；
- 把机器摘要当作人工阅读；
- 用未核验模型输出写政策含义；
- 隐瞒数据 / 模型 caveat。

## 8. 非声明

本规则不要求每篇候选文献都人工核验。它要求：凡要支撑正式论文 claim 的证据，必须达到 E3 或等价人工核验等级。
